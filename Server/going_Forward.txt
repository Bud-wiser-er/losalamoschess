# Demo Notes for Los Alamos Chess Server - Ethan (u21501212)

## Current Issues & Fixes (MUST DO BEFORE DEMO)
- **Port conflicts**: Check for processes on port 5000 with `lsof -i :5000` (Linux/Mac) or `netstat -ano | findstr :5000` (Windows). Kill with `kill -9 <PID>` or `taskkill /PID <PID> /F`. Run `npm run dev` after. Demo tip: "Port conflicts are common in dev; prod uses Docker/PM2."
- **Partial JSON in browser**: `/health` endpoint shows partial JSON in browser due to truncation. Use `curl http://localhost:5000/health` to show full output: {"status": "OK", "timestamp": "...", "uptime": ...}. Check for ad-blockers/extensions interfering.
- **Test failures**:
  - **integration.test.js (INT-06)**: Malformed JSON gives 500, not 400. Fixed in server.js error middleware (check for `entity.parse.failed`).
  - **websocket.test.js (WS-05)**: Wrong error message ("Invalid token" vs "Authentication error"). Fixed in config.js authenticateSocket.
  - **auth.test.js (AUTH-07, AUTH-08)**: Undefined user.id. Fixed response structure in /api/auth/register and /api/auth/login.
  - **security.test.js (SEC-07, SEC-08)**: Invalid input and XSS issues. Added Joi validation and sanitize-html for /api/auth/register.
  - **Test leakage**: Added --detectOpenHandles to jest and server.close in tests/server.test.js.

## Demo Flow (10-Minute Presentation)
1. **Start server**: `npm run dev`. Show console output.
2. **Health check**: `curl http://localhost:5000/health` (full JSON). Browser demo, explain partial view fix.
3. **Register**: `curl -X POST http://localhost:5000/api/auth/register -H "Content-Type: application/json" -d '{"username":"demoUser","email":"demo@ex.com","password":"strongPass123"}'`. Show tokens, user.id.
4. **Login**: `curl -X POST http://localhost:5000/api/auth/login -H "Content-Type: application/json" -d '{"email":"demo@ex.com","password":"strongPass123"}'`. Highlight bcrypt (12 rounds), rate limit (10/15min).
5. **Refresh token**: `curl -X POST http://localhost:5000/api/auth/refresh -H "Content-Type: application/json" -d '{"refreshToken":"..."}'`. Note 15m/7d expiry.
6. **Profile**: `curl -X GET http://localhost:5000/api/user/profile -H "Authorization: Bearer <accessToken>"`. Show auth middleware.
7. **WebSocket**: Use socket.io-client (e.g., simple script or online tester). Demo `join-game`, `make-move`, `chat-message`. Show broadcast.
8. **Logout**: `curl -X POST http://localhost:5000/api/auth/logout -H "Authorization: Bearer <accessToken>" -H "Content-Type: application/json" -d '{"refreshToken":"..."}'`.
